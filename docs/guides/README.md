# Guías de Desarrollo

Esta carpeta contiene guías prácticas para el desarrollo diario.

## Contenido sugerido

- **Setup local** (prerrequisitos, instalación, configuración, primera ejecución)
- **Ejecución de tests** (unitarios, integración, E2E, mutation, cobertura)
- **Calidad de código** (linting, static analysis, formatting, pre-commit hooks)
- **Convenciones** (naming, commits, branches, PRs, code review)
- **Debugging** (logs, breakpoints, profiling, tracing)
- **Despliegue** (Docker, CI/CD, environments, rollback)
- **Base de datos** (migraciones, seeds, backups, performance)
- **Observabilidad** (logs, métricas, trazas, alertas)
- **Seguridad** (secrets, dependencies, OWASP, penetration testing)

## Formato

- Markdown con pasos numerados y comandos copiables
- Separar por audiencia: `setup.md`, `testing.md`, `deploy.md`, etc.
- Referenciar scripts en `package.json`, `Makefile`, `justfile`, `Taskfile.yml`, etc.
